### Server Tag (tag di samping nama)
Tag resmi server ini: **NAME**. Siapa pun yang sudah menjadi member server boleh memakainya.
Cara pasang di PC / browser:
1. Klik ikon ⚙️ (User Settings) di samping username kamu (kiri bawah).
2. Buka **Profiles** (atau **Edit User Profile**).
3. Scroll ke bagian **Server Tag**, klik **Select**, lalu pilih server **Noname Studios Creative** (tag NAME). Tersimpan otomatis.
Cara pasang di HP:
1. Ketuk foto profil kamu di kanan bawah aplikasi.
2. Ketuk **Edit Profile**.
3. Scroll ke **Server Tags**, pilih tag **NAME**. Tersimpan otomatis.
Cara melepas (PC): buka bagian Server Tag yang sama, klik **X** di samping tag yang terpasang.
Catatan: hanya 1 server tag yang bisa dipasang dalam satu waktu. Warna & lambang tag diatur oleh server, member tidak bisa mengubahnya. Kalau tag server diganti admin, member perlu memasang ulang. Tag tidak muncul di pilihan? Pastikan kamu sudah bergabung di server ini dan aplikasi Discord sudah versi terbaru.

### Ganti nickname khusus di server ini
PC: klik kanan nama server (atau klik nama server di atas daftar channel) → **Edit Per-server Profile / Edit Server Profile** → isi **Server Nickname** → Save.
HP: buka server → ketuk nama server di atas → **Edit Server Profile** → ubah nickname → Simpan.
Nickname ini hanya berlaku di server ini, tidak mengubah username Discord.

### Mengatur notifikasi server
Klik kanan nama server (HP: ketuk nama server) → **Notification Settings**. Pilih **All Messages**, **Only @mentions**, atau **Nothing**. Bisa juga **Mute Server** untuk membisukan sementara.
Untuk 1 channel saja: klik kanan channel → **Mute Channel** / **Notification Settings**.

### Bot / member tidak bisa kirim DM ke kamu
Klik nama server → **Privacy Settings** → aktifkan **Direct Messages** (izinkan pesan dari member server). Bot Noname Store mengirim info pesanan lewat DM, jadi disarankan diaktifkan.

### Menyalin ID (user / channel / pesan)
PC: User Settings ⚙️ → **Advanced** → aktifkan **Developer Mode**. Setelah itu klik kanan user / channel / pesan → **Copy ID**.

### Boost server
Klik nama server → **Server Boost** → pilih jumlah boost. Membutuhkan langganan Discord Nitro atau membeli boost di Discord. Noname Store juga menjual **Server Boost** (harga & stok lihat bagian produk).

### Melaporkan pesan / member yang melanggar
Klik kanan pesan (HP: tekan lama) → **Report Message / Laporkan**. Untuk masalah di server ini, kamu juga bisa membuat ticket **Support** di NCS Ticket Center.

### Keamanan akun Discord
Aktifkan **2FA**: User Settings ⚙️ → **My Account** → **Enable Authenticator App**.
Jangan pernah membagikan token, password, atau kode QR login Discord ke siapa pun — admin Noname Store tidak akan pernah memintanya.
